# Orbit Code Assistant

Agentic Coding Assistant: Orbit Code

A minimalist super sleek design, with high readable write content and a dark mode toggle for comfortable nighttime reading UI, this will be a Agentic coding assistant chat UI. The background in chat bubbles feel deep, high contrast and subtle gradients for a premium aesthetic. A modern, icon button prompt box input featuring model selector and quick action tools for streaming code snippets.

NOT A ACTUAL IMPLEMNTATION, JAVASCRIPT, HTML AND CSS only, not backend for the frontend prototype structure.

A sleek suspended left sidebar with session history and options to add new sessions, with smooth collapse animations and hover-state transparency effects, can be grouped by date or tags. 

On the right at the top, four icon, specifically for tools, browser, background task and three dots with drown menu.

On the bottom of side left bar, user profile settings with a sign-out button and dark mode toggle.

Ensure the interface remains responsive and minimalist across all desktop screen sizes.

Use icon instead of button text, soft border, and rounded corners for a modern aesthetic.

Incorporate subtle shadow effects to enhance depth and visual hierarchy.

Use a paper cream color vibes palette to create a warm and inviting professional interface experience.

The primary font should be a clean, readable sans-serif typeface for improved legibility.

Important: in chat, message from assistant should text plain, not mount in bubbles item, only users messages will appear in a distinctive speech bubble.

This minimalist approach will emphasize focus on the conversational content throughout the application.

Use tailwind.css and React for the implementation of this design.

Background has fancy tone, feels far and deep, with soft dots design and gradient tone. 

Prompt box is very flexible and suitable for high experience.
